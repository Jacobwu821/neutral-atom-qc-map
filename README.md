# 中性原子量子计算知识地图

一个静态网页，把中性原子量子计算机的完整实验流程、23 个知识模块、148 条掌握要求、63 篇核对过的文献和 54 个术语串在一起。

- **实验流程**：一轮实验的 9 个步骤。点开任意一步，可以看到它直接用到的知识、前置知识树和该读的文献。
- **知识树**：8 层、23 个模块之间的依赖关系。
- **文献**：里程碑时间线，以及可筛选的文献列表。
- **术语**：常用术语的一句话解释。

## 修改内容

所有数据都在 `gen_data.py` 里。改完后运行下面的命令，重新生成 `data.js`：

```bash
python3 gen_data.py
```

页面本身只有 `index.html`、`styles.css`、`app.js` 和 `data.js`，不需要构建，直接用 GitHub Pages 托管即可。
